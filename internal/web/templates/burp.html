Integrasi Burp Suite

BugHound menemukan kandidat bug; kamu memvalidasinya manual di Burp Repeater. Integrasi ini menjembatani keduanya tanpa pindah-pindah tool — dari sisi Burp: sebuah extension menarik temuan dari BugHound, lalu kirim request-nya ke Repeater.

BugHound temukan → API /api/v1/findings → tab “BugHound” di Burp → Repeater (Send manual)

Jalan di Burp Community Kamu belum butuh Burp Pro: Repeater dan memuat extension .jar sendiri tersedia di Community. Pro hanya perlu untuk active scanner, Intruder penuh, atau simpan project — bukan syarat alur ini.

Read-only & tanpa auto-submit: extension hanya membaca dari BugHound (GET) lalu memuat request ke Repeater. Mengirim ke target tetap aksi manualmu lewat tombol Send.

1 · API BugHound (read-only)

Sumber data extension. Auth HTTP Basic dengan akun BugHound-mu (GET, tak perlu CSRF). Tanpa kredensial → 401.

EndpointKeterangan
GET /api/v1/findings?program=<nama>Daftar temuan satu program. Opsi: run_id, status, severity (koma), include_duplicates=1.
GET /api/v1/findings/{id}Satu temuan lengkap (termasuk evidence.request).

2 · Extension Burp (Montoya)

Sumbernya ada di repo: burp-ext/. Build sekali, load ke Burp.

Build
cd burp-ext
gradle shadowJar
# hasil: build/libs/bughound-burp.jar

Load: Burp → Extensions → Add → type Java → pilih bughound-burp.jar. Muncul tab BugHound.

Pakai: di tab BugHound isi URL BugHound ({{.BaseURL}}), user, pass, dan nama program → Muat temuan → pilih baris → Kirim ke Repeater → tekan Send sendiri untuk validasi.

Prasyarat: JDK 17+ dan Gradle 8+. Detail & troubleshooting (versi montoya-api) ada di burp-ext/README.md.

Catatan keamanan

  • API dipakai hanya GET — extension tak mengubah data BugHound, tak memicu scan, dan tak pernah mengirim request ke target otomatis.
  • Egress / scope guard / rate limiter BugHound tetap mengatur scan BugHound sendiri; extension ada di luar jalur itu (hanya handoff baca → Repeater).
  • Scope saat validasi: Repeater mengirim ke mana pun kamu tekan Send — pastikan target in-scope program bug bounty-mu. Itu tanggung jawabmu di Burp, sama seperti Repeater biasa.
  • Kredensial hanya di memori extension (tak dipersist). Untuk BugHound non-lokal, taruh di belakang TLS agar Basic auth tak lewat polos.
