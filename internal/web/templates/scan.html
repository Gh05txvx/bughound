The preset (tags/severity/stealth/API route) is saved per program & automatically fills this form when the same program is chosen. It only affects which templates/wordlist run — not scope, egress, rate limit, or secrets.

Stealth lowers the footprint on a SOC-monitored target: the rate is clamped to ≤3/s, one connection, a browser User-Agent, a narrower URL scope. Non-destructive is always on — no DoS payloads & no blind/OAST callbacks; the scan looks for candidate bugs for you to verify manually, it does not change the target's configuration.

Adds ~thousands of real API paths (ordered by frequency) to the ffuf engine to find unlinked API endpoints (e.g. /api/v1/…, /rest/…). Large volume & slower — enable it for API-heavy targets. Each probe still goes through the scope-enforced egress proxy (like any other wordlist); non-destructive.

Headers are injected into every engine request (-H; ZAP through a Replacer rule) so the scan reaches content behind a login. The header value is never echoed to the form, logged, or put in a report — it is redacted from evidence before it is stored. The headers only ride on requests that pass the scope guard; a redirect out of scope is still denied at egress. Logout routes (logout, sign-out, logoff, …) are skipped by every engine & crawler so the session does not die mid-scan — test those routes with a scan without a session. The RoE box is required when a session is used.
