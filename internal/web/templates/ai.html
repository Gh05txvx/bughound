MCP / AI: what-if analysis

This menu connects BugHound to an LLM API using your own API key. When a finding is opened, BugHound sends the scrubbed finding context to the active provider to produce a what-if card (hypotheses + a manual validation plan) in the finding detail. Pick one provider as active, for example Groq (free tier) when your Anthropic credit runs out.

  • 🔒 API key = secret: stored encrypted in the vault, redacted, never written to a log/report/commit; every access is audited.
  • 🌐 Limited egress: only to api.anthropic.com or api.groq.com (control plane, hardcoded), separate from the scan scope guard. Active only when the active provider's key is set.
  • ✂️ Evidence is scrubbed before it is sent (headers/credentials/PII redacted and trimmed).
  • 🧭 Advisory: non-destructive test suggestions to run by hand in Burp, with no auto-submit. The result is cached per finding (saving your API cost).
